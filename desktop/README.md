# 明想桌面工作台

Electron 壳层加载现有 MingWant Web，并为 Lumina、Dola、Dreamina 人工网页视频任务提供按平台隔离的动态账号池。每个账号使用独立的持久化浏览器分区，项目不会保存账号密码，也不会向远端页面注入自动操作脚本。

## 本地启动

先按仓库说明启动 Web 与后端，再启动桌面壳层：

```bash
cd desktop
bun install
bun run dev
```

桌面壳层默认加载 `http://localhost:3000`。需要连接其他可信部署时，显式设置 `MINGWANT_WEB_URL`：

```powershell
$env:MINGWANT_WEB_URL = "https://你的可信部署"
bun run dev
```

画布在 Electron 中提交视频生成后，会打开“网页视频工作台”。平台顺序为 Lumina（默认）、Dola、Dreamina；已有节点或本地平台偏好仍保持原选择。单视频节点和分镜批量任务都可明确选择平台，任务只会分配给同平台账号。在工作台中可按需新增多个账号（当前最多 100 个）；每个新账号先选择所属平台，在独立网页容器中完成登录，再点击“标记已登录”加入调度。网页下载到视频后，点击“回填当前节点”将文件交回画布的既有媒体存储流程。

参考素材会暂存到 Electron 用户数据目录的 `video-workflow/inputs`，视频下载保存在系统下载目录的 `MingWant Studio` 文件夹。账号 Cookie 和站点存储只保存在对应 Electron 持久化分区中。

## 每账号代理

新增账号前可点击“新账号网络”预设代理，确保该账号第一次访问平台网页前就使用指定出口；现有空闲账号可从工作台顶栏单独修改。每个账号的代理只作用于自己的持久化 Session，并覆盖平台网页、OAuth 子窗口和下载流量。支持 `http://`、`https://`、`socks4://` 与 `socks5://` 地址，也支持代理用户名和密码；密码通过 Electron `safeStorage` 交给操作系统加密，`accounts.json` 和工作台状态都不会包含明文密码。

代理改变后会停止当前加载、关闭该 Session 的旧连接并回到平台首页，同时把账号恢复为“需要登录”，必须在新网络环境中人工确认登录后才能重新参与调度。工作流不会随机修改 User-Agent、Canvas、WebGL、时区等浏览器指纹，也不会向远端页面注入伪装脚本；这些做法容易制造互相矛盾的特征，并可能违反平台规则。代理是否允许多账号使用仍应以对应平台条款为准。
