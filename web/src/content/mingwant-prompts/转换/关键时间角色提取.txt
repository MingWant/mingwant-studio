# 角色与时期提取指令

## 任务
阅读以下小说正文，提取所有出现的角色，并分析**主角和关键人物**的重大变化节点，输出标准人物表。

## 角色分级规则

### 主角和关键人物（需标注时期）
满足以下任意条件之一的角色，视为主角或关键人物，需要标注时期：
- **主角**：故事第一人称视角的"我"，或贯穿全文的核心主人公
- **核心配角**：在全文中出场次数≥5次，或对主线剧情有重要推动作用的角色
- **重要关系人**：与主角有直接血缘、婚姻、主仆、师徒等重要关系的角色
- **关键对手**：与主角有重大冲突或对抗关系的角色

### 次要角色和边缘角色（不标注时期）
不满足上述条件的角色，包括：
- 出场次数少于5次的路人角色
- 只在某个片段出现的临时性角色
- 工具性角色（如传话的小厮、开门的门房等）
- 群体性角色（如"围观的百姓"等）

**判断原则**：如果去掉这个角色不影响主线剧情，则视为次要/边缘角色，不标注时期。

---

## 时期划分触发规则

**仅对主角和关键人物进行时期划分**，以下任意一种变化发生时，视为新时期的开始：

- **年龄阶段变化**：跨越幼年/青少年/青年/中年/老年任意年龄段边界
- **身份变化**：社会身份或职位发生重大转变，如丫鬟→姨娘、平民→官员
- **居所变化**：长期居住地发生重大迁移，如农村→进京→侯府
- **家庭变化**：婚姻或生育等重大家庭事件，如未婚→成婚→生子
- **重大遭遇**：对人生轨迹产生根本影响的事件，如入狱、流放、丧偶、重病
- **外形装扮变化**：外形或装扮发生显著改变，如女扮男装、乔装改扮、削发为尼等，恢复原装扮时视为新时期

---

## 年龄段定义（用于年龄阶段变化判断）

| 年龄范围 | 对应时期 |
|---|---|
| 1岁（含）～10岁（不含） | 幼年时期 |
| 10岁（含）～20岁（不含） | 青少年时期 |
| 20岁（含）～30岁（不含） | 青年时期 |
| 30岁（含）～40岁（不含） | 中年时期 |
| 40岁（含）以上 | 老年时期 |

---

## 输出格式规范

### 格式模板
```
角色名称: [角色名], 别名: [别名1、别名2], 性别: [男/女/未知], 时期: [时期1、时期2、时期3]
```

### 字段说明

**1. 角色名称（必填）**
- 填写角色在文中最常用的称呼
- 如果是主角且文中以"我"自称，写作"我"

**2. 别名（选填）**
- 填写该角色在文中出现的其他称呼，用顿号分隔
- 包括：小名、昵称、职位称呼、关系称呼等
- 示例：小翠、翠儿、丫鬟（指同一人的不同称呼）
- 如果没有别名，写：无

**3. 性别（必填）**
- 填写：男 / 女 / 未知
- 若文中未明确性别，填：未知

**4. 时期（主角和关键人物必填，次要角色不填）**
- **主角和关键人物**：按时间顺序列出所有时期，用顿号分隔
- **次要角色和边缘角色**：删除整个"时期:"字段，不写
- 时期名称须简短精准（2-6字），直接反映该阶段最核心的身份、状态或装扮
- 示例：农村时期、进京时期、侯府姨娘时期、女扮男装时期

---

## 输出规则

1. **只输出人物表**，不需要任何其他内容（不要有标题、说明、备注）
2. **每个角色独占一行**，严格按照输出格式模板
3. **主角和关键人物必须标注时期**，次要角色不写时期字段
4. **时期按故事发展顺序排列**
5. **角色按重要性排序**：主角最前，关键人物次之，次要角色最后
6. **不要遗漏角色**：所有在文中出现的角色都要提取，哪怕只出现一次

---

## 特别注意

1. **次要角色的输出格式**：次要角色不写"时期:"字段，格式为：
   ```
   角色名称: 张叔, 别名: 无, 性别: 男
   ```
   而非：
   ```
   角色名称: 张叔, 别名: 无, 性别: 男, 时期: 无  ← 错误！不要写时期字段
   ```

2. **时期名称要求**：
   - 简短（2-6字）
   - 精准（直接反映核心身份/状态）
   - 不要用年龄段（如"青年时期"），除非没有其他更精准的描述
   - 优先用身份、居所、装扮命名

3. **别名提取要求**：
   - 只提取指向同一个人的不同称呼
   - 不要把不同的人当成别名
   - 不要把描述性语言当成别名（如"那个高个子男人"）

4. **性别判断**：
   - 无法从文中判断性别时，填：未知
   - 不要通过名字推测性别
