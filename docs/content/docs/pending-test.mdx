# 待验证

## 品牌与基础能力

- 检查登录、首页、工作区侧栏、管理后台、邮件和导出文件名是否统一显示“明想 MingWant Studio”。
- 确认原自由画布、节点、连线、导入导出、短剧工作流、素材库、任务中心、Agent 和管理后台均可正常使用。
- 验证旧 `infinite-canvas:*` 本地存储键和 MCP 工具名仍能读取既有数据并连接 Agent。

## 电商画布模板

- 从画布列表点击“15 条带货模板”，确认成功创建并进入新画布。
- 确认画布包含 5 个真人素材占位、项目/授权/身份/商品节点、5×3 创意矩阵、15 个五镜头分镜、首尾帧母版、15 个成片槽位、QA 与交付节点。
- 检查所有节点布局、背板父子关系、连线、小地图、缩放和大画布性能。
- 将真实视频拖到 5 个素材占位节点，验证替换、持久化、远端同步和重新打开。
- 为一个分镜复制首尾帧母版并生成图片，再按分镜创建 5 个 6 秒视频节点；同时选中 5 段视频和对应空白成片槽位执行合并，确认结果原位填入槽位、保留既有 QA 连线且最终时长接近 30 秒。
- 不选择空白槽位时合并至少 2 段视频，确认仍按上游行为在源视频右侧创建新成片节点。
- 逐条验证 30 秒、9:16、字幕安全区、身份一致性、商品准确度、口型、手部与物理连续性。

## 项目与后端工作流

- 创建 `commerce-video` 项目，确认后端实例包含 Brief、授权、身份、商品、创意矩阵、首尾帧、生成、质检和交付九步。
- 在电商项目详情点击“带货画布”，确认一键创建同一套 15 条工作流并自动关联当前项目。
- 创建 `short-drama` 项目，确认仍使用原七步短剧流程。
- 验证步骤状态流转、失败重试、任务产物登记、项目修订号和删除回滚。
- 验证首页和项目列表返回并显示工作流总步骤、已完成步骤与电商项目完成度。
- 验证全局素材库、项目素材页、画布素材选择器和节点素材菜单均支持商品、品牌、授权文件分类；电商身份、商品与授权节点保存时自动归类。
- 验证电商项目在首页、项目列表和详情页不会显示误导性的“准备故事/添加章节”下一步。

## 明想提示词库与参考方法

- 打开侧栏“提示词库”，确认显示 49 份原始模板，并按 AI 助手、二次创作、分镜生成、图片提示词、推理提示词、视频提示词、角色提取和格式转换八类筛选。
- 验证名称与用途搜索、原文预览、变量识别和复制全文；随机抽查原文与用户提供文件完全一致。
- 在画布文本节点打开“预设”，确认显示“明想库”来源并能按需读取、插入完整模板。

- 阅读“参考爆款视频的项目化制作方法”，确认教程有效步骤已转为供应商无关流程，第三方去水印站未作为官方能力纳入。

## UI/UX 与异常容错

- 在允许剪贴板写入和拒绝剪贴板写入两种情况下测试复制；只有真实写入成功才提示“已复制”，失败时应明确提示手动复制。
- 在 1280px 桌面视口检查提示词库搜索框与分类筛选保持同一行；在手机视口检查工具栏自然换行且页面无横向溢出。
- 新建“15 条带货模板”，确认首屏聚焦“项目输入与授权边界”并能看清首阶段节点，而不是显示大面积空白或缩小整条超宽工作流。
- 模拟技能激活列表和任务列表返回空对象、空值等异常结构，确认画布降级为空列表且不会整页白屏。
- 打开登录和注册页，确认控制台不再出现 Ant Design `iconPosition` 弃用警告。

## Electron 多账号网页视频工作流

- 启动现有 Web 与后端后运行 `desktop`，确认 Electron 主窗口能加载登录页、项目页和画布；普通浏览器访问同一部署时仍使用原有模型生成路径。
- 首次进入且没有已保存平台偏好时，确认普通视频节点、视频配置节点、分镜批量弹窗及新增账号下拉框都将 Lumina 排在第一位并默认选中；已有节点或本地平台偏好仍保持原选择。
- 在网页视频工作台分别新增 Lumina、Dola、Dreamina 账号，并对 4 个以上账号执行重命名、停用和重新启用，确认账号数量没有写死；新账号完成登录并点击“标记已登录”前不得接收任务，重启 Electron 后账号名称、所属平台、启用状态和各自登录态仍保留。
- 分别登录多个 Lumina、Dola、Dreamina 账号，确认 Cookie、缓存、Local Storage 和登录状态互不共享；“清空登录态”和“删除账号”必须二次确认，执行后只影响目标账号。
- 新增账号前分别配置 HTTP(S)、SOCKS4 和 SOCKS5 代理，确认平台网页第一次发起请求前已经使用该账号代理；直连账号与代理账号的出口 IP 不互相影响，OAuth 子窗口和视频下载继续使用所属账号的同一个 Session 与代理。
- 使用带用户名、密码的代理，确认认证只响应匹配代理主机的 Proxy Auth 挑战，不会把代理凭据提交给平台网页；`accounts.json`、工作台状态和界面不得出现明文密码，系统安全存储不可用时必须明确拒绝保存密码。
- 修改空闲账号的代理，确认旧连接和 OAuth 子窗口被关闭、页面在新代理下重新加载、账号自动回到“需要登录”且确认前不接收任务；任务进行中禁止切换代理，切回直连时必须明确提示会暴露本机出口 IP。
- 输入缺少协议、包含路径、端口越界或协议不受支持的代理地址，确认保存明确失败且不以直连掩盖错误；代理不可达或认证失败时页面应显示加载错误，不能静默回退直连。
- 在未配置视频 API 的 Electron 环境中，从普通视频节点和视频配置节点分别选择 Lumina、Dola、Dreamina 提交任务，确认自动打开工作台、只分配同平台最久未使用的空闲账号、复制提示词并显示平台、时长、画幅、清晰度、声音和水印参数。
- 为视频节点连接图片、视频和音频参考，确认工作台的任务素材目录包含可读取的本地文件、生成说明和无法直接导出的 HTTP(S) 参考链接；超大或无效素材应明确失败。
- 批量提交多条分镜视频时分别选择 Lumina、Dola 和 Dreamina，确认任务按平台进入对应账号池；任务数不超过同平台可用账号数时并行分配，超出的任务留在等待队列，其他平台的空闲账号不得抢占；完成或取消任务后账号池能继续调度下一项。
- 在账号网页容器中下载非视频文件，确认不会误关联任务；下载 MP4、WebM、MOV 或 M4V 后，必须点击“回填当前节点”才写回画布，点击“忽略此下载”后可重新选择正确结果。
- 确认回填后沿用现有媒体存储：节点状态、尺寸、时长、账号名称和源文件名正确，项目资源同步失败时仍保留本地结果并明确提示。
- 生成中从画布停止任务或从工作台取消任务，确认账号立即释放、节点与批量项状态一致；页面刷新后旧桌面任务应被取消并提示重新生成，不得错误绑定后台任务。
- 关闭工作台窗口后确认窗口仅隐藏、账号容器和进行中的下载不被意外销毁；退出主窗口后所有等待调用均明确结束。
- 验证远端账号容器没有 Node.js、预加载脚本和 Electron IPC 权限，只允许 HTTPS 导航，站点权限默认拒绝；工作台本地页面的 CSP 不允许加载远端脚本。
- 确认工作流只做 Session、站点存储和代理隔离，不随机伪装 User-Agent、Canvas、WebGL 或时区，不向远端页面注入指纹脚本。
- 分别实测 Lumina、Dola 与 Dreamina 的登录、OAuth 弹窗、验证码、视频生成和下载流程在 Electron 当前版本中的兼容性；Lumina 应打开 `https://ai.byteplus.com/lumina`，工作流不得注入脚本、自动点击或自动处理验证码。
