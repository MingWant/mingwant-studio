# 明想个人提示词素材

本目录保存用户自有的 49 份原始提示词，前端会按“分类目录 / 文件名”自动建立提示词清单。

## 使用约定

- 原始 `.txt` 内容按用户提供版本保留，不在加载阶段重写或压缩。
- 这些材料大多是驱动文本模型产出最终图片、视频或分镜提示词的元提示词，因此画布只在文本节点的预设面板中提供“明想库”入口。
- 模板中的 `{{变量名}}` 需要结合项目资料替换；独立提示词库页面会在预览时自动提取并显示这些变量。
- 新增模板时，只需在对应分类目录放入 `.txt` 文件；文件名会成为模板名称。

## 当前分类

- `AI助手`：11 份
- `二创`：1 份
- `分镜`：8 份
- `图片`：9 份
- `推理提示词`：8 份
- `视频`：8 份
- `角色提取`：1 份
- `转换`：3 份

提示词属于创作方法资料，不替代肖像授权、商品事实、广告宣称和投放平台审核。
